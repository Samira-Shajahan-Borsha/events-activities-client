# 🎟️ EventHub — Events & Activities Platform

EventHub is a modern events and activities discovery platform built with **Next.js 16**, **TypeScript**, **Tailwind CSS**, and **Shadcn/UI**.  
The frontend delivers a seamless user experience for discovering events, managing activities as a host, and overseeing the platform as an admin.

---

## 🎯 Project Overview

EventHub bridges the gap between digital discovery and real-world participation through a clean, responsive, and role-based interface.

### Core Goals

-   Discover local events with advanced filtering
-   Enable hosts to manage events efficiently
-   Provide admins with full platform control
-   Ensure secure authentication and smooth user experience

## 🛠️ Tech Stack

-   **Framework:** Next.js 16 (App Router)
-   **Language:** TypeScript
-   **Styling:** Tailwind CSS
-   **UI Library:** Shadcn/UI
-   **State Management:** TanStack Query (React Query)
-   **Forms:** React Hook Form + Zod
-   **Icons:** Lucide React
-   **Image Hosting:** Cloudinary
-   **Authentication:** JWT-based auth flow

---

## 🔐 Key Features

### 👤 User Profile Management

-   Create and update personal profiles with bio and interests
-   Upload profile images using Cloudinary
-   Interest-based personalization for better event discovery
-   Secure profile editing with JWT authentication

---

### 🧑‍💼 Host Dashboard

-   Create, edit, and cancel events
-   Track participants and payment status
-   View total earnings from ticketed events
-   Dedicated dashboard with role-based access

---

### 🛡️ Admin Dashboard

-   View and manage all registered users
-   Block or unblock users for moderation
-   Approve, suspend, or manage hosts
-   Platform-level analytics and statistics

---

### 🎫 Event Discovery & Checkout

-   Browse and filter events by:
    -   Category
    -   Date
    -   Availability
-   Join free or paid events
-   Secure checkout flow for ticketed activities
-   Instant booking confirmation
